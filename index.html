Questions before you buy.

Do I need to know n8n?

You need to import a workflow and add credentials. The setup guide walks through it; the deploy script creates the database work. If you are not technical, buy only if you have someone who can run it.

Do I need Meta business verification?

Yes, for a production number. The kit handles the webhook and templates; Meta handles the business review. The test number is QA-only and limited to a handful of verified recipients.

Does it work in Hebrew and Arabic?

Yes — 18 languages, with RTL cards. It detects Hebrew, Arabic, Thai, Lao and Cyrillic automatically; the Language row switches any session.

Can I use it for clients?

With the agency licence, yes, for unlimited client projects. The retail licence covers one business. You may not resell or redistribute the source itself.

What if it breaks?

Twelve months of email support. Send the workflow name, execution ID and error. Refund within 14 days if it does not import and run as documented.

Does the template contain your data?

No. It ships with placeholders only: no tokens, real phone-number IDs, personal names, test logins or embedded credentials. privacy_check.py enforces this.

Do I need a licence key?

No. The product is n8n workflow JSON; a key cannot enforce a copyable file. Your order receipt and the LICENSE.txt inside the zip are the licence record.

Is the WhatsApp image a real phone screenshot?

Yes. The customer-view image is an actual WhatsApp capture from the Meta test number, using the test name “Atlas Testing”. It shows a real booking, real day and time pickers, and the booking receipt. No real customer data is shown.

What is tested, and what is not?

Tested: 530 logic checks, 20 helper tests, a 46-check end-to-end run of the real workflow (including a real Google event created and cancelled), trigger signature and status-filter cases, static audit 0/0, privacy gate, clean 40/7 import, and a paid test-mode checkout at $39. Not yet: a live Outlook tenant run, live file delivery (test mode disables downloads), Lemon Squeezy store verification, and a production WhatsApp number.

Do I need a company to buy it?

No company is needed to buy the template. A production WhatsApp number may require Meta business verification in your own account; that is between you and Meta, not part of this purchase.

Does it work with Outlook?

Yes. Set CALENDAR_PROVIDER=outlook and the helper talks to Microsoft Graph with app-only credentials (no user sign-in, no consent screen). Every booking also carries Add-to-Google and Add-to-Outlook links for the customer. Google Calendar remains the default. Calendly is not supported.

Can the customer get back to the menu?

Yes. Every list has a Main menu row, and typing menu (or start over, restart, home, 0) returns to the menu from any step. back goes one step back. Hours, prices and human answers do not cancel a booking in progress.
