Questions before you buy.

Do I need to know n8n?

You need to import a workflow and add credentials. The setup guide walks through it; the deploy script creates the database work. If you are not technical, buy only if you have someone who can run it.

Do I need Meta business verification?

Yes, for a production number. The kit handles the webhook and templates; Meta handles the business review. The test number is QA-only and limited to a handful of verified recipients.

Does it work in Hebrew and Arabic?

Yes — eight languages, with RTL cards. It detects Hebrew, Arabic, Thai, Lao and Cyrillic automatically; the Language row switches any session.

Can I use it for clients?

With the agency licence, yes, for unlimited client projects. The retail licence covers one business. You may not resell or redistribute the source itself.

What if it breaks?

Twelve months of email support. Send the workflow name, execution ID and error. Refund within 14 days if it does not import and run as documented.

Does the template contain your data?

No. It ships with placeholders only: no tokens, real phone-number IDs, personal names, test logins or embedded credentials. privacy_check.py enforces this.
